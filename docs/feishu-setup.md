# 飞书接入指引（约 10 分钟）

lifehub 需要飞书的两样东西：**推送**（发晨报给你）和 **录入**（你在飞书里发话给机器人）。
按下文配置，凭据最终都填进 `config.toml`。

## 第 1 部分：群机器人 Webhook（晨报推送，约 2 分钟）

1. 打开飞书，随便进一个**群**（或新建一个只有自己的群，如「中台」）
2. 群设置（右上角 ⋯）→ **群机器人** → **添加机器人** → 选 **Custom Bot（自定义机器人）**
3. 安全设置选 **「自定义关键词」**，填：`中台`
4. 点完成后复制 **Webhook 地址**（形如 `https://open.feishu.cn/open-apis/bot/v2/hook/xxxx`）
5. 粘贴到 `config.toml` 的 `webhook = ""` 里 ✅

## 第 2 部分：自建应用（对话录入，约 8 分钟）

> 个人飞书账号也能创建，会自动建一个你自己的组织，免费。

1. 打开 **飞书开放平台**：<https://open.feishu.cn/app>
2. 点 **创建企业自建应用**，名称填 `中台`，描述随意
3. 创建后进入应用，左侧 **凭证与基础信息**：复制 **App ID** 和 **App Secret**
   → 填进 `config.toml` 的 `app_id` / `app_secret`
4. 左侧 **添加应用能力** → 添加 **机器人**
5. 左侧 **权限管理**，搜索并开通这两条：
   - `im:message`（获取与发送单聊、群组消息）
   - `im:message:send_as_bot`（以应用身份发消息）
6. 左侧 **事件与回调** → 订阅方式选 **「使用长连接接收事件」**（重要！这样不需要公网 IP）
   然后点 **添加事件**，搜索并添加：**接收消息 `im.message.receive_v1`**
7. 左侧 **版本管理与发布** → 创建版本 → 填个版本号（如 1.0.0）→ 提交发布
   （你自己的组织，管理员就是你自己，审核秒过）
8. 回到飞书客户端：搜索你的应用名「中台」，**发一条消息给它**（如 `帮助`）

## 验证

```powershell
python -m lifehub.cli report   # 群里应收到晨报（测试推送）
python -m lifehub.cli bot      # 启动后，在飞书给机器人发「午饭 35」或「明天买牛奶」
```

收到机器人回复「已记 ✓」即全通。
